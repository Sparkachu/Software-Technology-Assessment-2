### Part H - Reflection

Before using AI, I created and ran the SmartCare appointment booking program in Python. The program stored the patient name, practitioner name and appointment time. The enhanced version used a list, dictionaries and functions to store and display multiple appointments.

I used Microsoft Copilot as a tutor to help explain the code and identify limitations. It helped me understand problems such as limited input validation, conflicting appointment times and the fact that the data is not permanently stored. However, Copilot said that display_appointments() was never called. This was correct for the code I provided to Copilot because I accidentally left out the display_appointments() call from the end of the original program. This showed me that AI responses are not always correct.

I verified the AI output by comparing it with the original code and running different tests. I tested a normal appointment, a blank patient name, conflicting appointments and unusual inputs such as None. I also compared the human-written program with the version generated by Copilot.

The engineering work that remained included checking the AI suggestions, testing the program and deciding which improvements were appropriate. For my controlled improvement, I added validation to prevent an appointment from being created with an empty practitioner name.
